# CLINE HARNESS OVERRIDE RULES

1. **System Authority**: Ikuti seluruh aturan di `AGENTS.MD` dan `/.guidance/Agent_rules.md` sebagai prioritas tertinggi di atas kebiasaan default-mu.
2. **No Blind Directory Traversal**: Dilarang memindai atau mencari file komponen secara manual. Jika membutuhkan komponen UI dari `folder-a`, langsung baca `/.docs/catalogue.json` sebagai indeks tunggal.
3. **Atomic Scope Only**: Bekerjalah hanya pada folder atau komponen spesifik yang ditugaskan. Baca `readme.md` atomik di dalam folder komponen tersebut sebelum melakukan perubahan kode.
4. **Mandatory Session Rituals**:
   - Di awal sesi, jalankan perintah `npm run session:start` melalui terminal dan baca status aktif di `/.guidance/boards.md`.
   - Sebelum mengakhiri sesi atau melakukan *handoff*, rangkum temuan penting ke `/.docs/session-notes.txt`, perbarui `/.guidance/boards.md` (maksimal 3 poin / 8 baris), lalu wajib jalankan `npm run verify`.
5. **Fail-Fast**: Jika gagal mengakses file atau perintah terminal gagal 2 kali berturut-turut, segera hentikan eksekusi, catat kendala di `boards.md`, dan laporkan tanpa melakukan *looping*.
